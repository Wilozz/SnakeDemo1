# SnakeDemo1

A classic Snake game that runs in the browser. Guide the green snake to the red apple to eat it and grow. Hitting a wall or your own tail ends the game.

## Start the game

No install or build step is needed.

1. Open `index.html` in any modern web browser (double-click it, or run `xdg-open index.html` / `open index.html`).
2. Press Space to start.

Or serve it locally and visit http://localhost:8000:

```
python3 -m http.server 8000
```

## Controls

- Arrow keys or WASD: steer the snake
- Space: start, or play again after a game over
